# Recursos da tela de entrada

Imagem e identidade visual adaptadas do projeto do responsável
[pawprint-clinic-welcome](https://github.com/JoaoKelvinDev/pawprint-clinic-welcome),
referência `5b93d996cec2771700449bc22929edd12189a238`.

- `vet-hero.jpg`: imagem original do projeto, sem edição.
- `fonts/nunito-variable.ttf`: Nunito, fonte variável oficial do
  [Google Fonts](https://github.com/google/fonts/tree/main/ofl/nunito).
- `fonts/fraunces-variable.ttf`: Fraunces, fonte variável oficial do
  [Google Fonts](https://github.com/google/fonts/tree/main/ofl/fraunces).
- `fonts/OFL-Nunito.txt` e `fonts/OFL-Fraunces.txt`: licenças SIL Open Font
  License 1.1 distribuídas com as fontes, preservadas integralmente.

Os arquivos são servidos pela aplicação. A tela não consulta Google Fonts,
Lovable ou GitHub no navegador para carregar esses recursos. As famílias CSS
`Login Nunito` e `Login Fraunces` são usadas somente pela tela de entrada.
